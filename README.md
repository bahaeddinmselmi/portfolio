# bahaeddin.dev — Portfolio

Personal portfolio of **Baha Eddin Mselmi** — Serial Founder and AI Infrastructure Engineer building for MENA and EMEA markets.

Live: **[recouvr.me/portfolio](https://recouvr.me/portfolio/)**

---

## Stack

- **React 18** + **TypeScript**
- **Vite** — build tooling
- **Tailwind CSS v3** — styling
- **Framer Motion** — animations
- **Lucide React** — icons
- **EmailJS** — contact form
- **GitHub Actions** → **GitHub Pages** — CI/CD

---

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build   # outputs to dist/
```

## Deploy

Pushes to `main` trigger the `deploy.yml` GitHub Actions workflow which builds and deploys to GitHub Pages automatically. No manual steps needed.
